## 📌 عن المشروع (About The Project)
**منصة ليالي** هي تطبيق ويب متكامل ونظام إداري شامل تم تصميمه وبرمجته باستخدام إطار العمل **Laravel**. 
يستهدف النظام إدارة الأعمال والعمليات الداخلية بكفاءة عالية، موفراً لوحة تحكم (Dashboard) مرنة وقوية تتيح للمديرين تتبع البيانات، إدارة المستخدمين، وتنظيم المهام بسهولة وأمان.

## ✨ المميزات (Features)
- 🔐 **نظام صلاحيات متقدم (Roles & Permissions):** إدارة وصول دقيقة للمستخدمين والمشرفين.
- 📊 **لوحة تحكم إدارية (Dashboard):** عرض إحصائيات حية وتقارير شاملة.
- 🗄️ **إدارة قواعد بيانات متينة:** هيكلية مصممة لاستيعاب وعرض البيانات بكفاءة.
- ⚡ **أداء عالي وحماية:** تطبيق معايير الأمان لحماية البيانات.
- 📱 **واجهة متجاوبة (Responsive UI):** لوحة تحكم تعمل بامتياز على الشاشات المختلفة.

## 🛠️ التقنيات المستخدمة (Built With)
- **Backend:** PHP (Laravel Framework)
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** MySQL
